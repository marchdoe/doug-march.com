## Curated References

> Full library — select the 2-3 references that best serve today's direction; ignore the rest.

### OWN GOLD STANDARD (2026-04-28, risk 8): drenched terracotta Specimen — a single hue committed across ~70% of the viewport, type waterfall reversed out of the field, labels and size markers treated as design material. Rated the benchmark: committed gestures, not hedges.
- **Tags**: specimen / warm / moderate

### OWN HIGH-WATER MARK (2026-06-13): Split as argument — left panel is the thesis (one enormous word, 178px Anton, fairway green drench), right panel is the evidence (clean cataloged rows in pine-white). The split earns itself because the two halves NEED each other; productive irony (the word for smallness is the biggest object on the page).
- **Tags**: split / energetic / moderate

### Poster logic taken literally: the page IS a typographic poster. One statement at viewport scale, type as image, zero supporting UI above the fold. The confidence comes from what is withheld.
- **Source**: https://davidrudnick.org
- **Tags**: poster / dramatic / sparse

### Studio Dumbar / DEMO energy: aggressive grotesk at full bleed, one accent color pushed to full saturation, rhythm from repetition of a single bold move rather than variety of small ones.
- **Source**: https://studiodumbar.com
- **Tags**: poster / energetic / moderate

### Klim type specimens: a waterfall of the same face doing different jobs — display cut at 120px above dense text settings, with size labels, foundry numbers, and hairline rules doing the layout work. Dense but never messy because every element sits on the same strict grid.
- **Source**: https://klim.co.nz
- **Tags**: specimen / serious / dense

### Pangram Pangram specimen pages: single-hue drenched field, type reversed out, weight changes (thin → black) used as the page's rhythm instead of imagery. Proof that a specimen can feel warm, not clinical.
- **Source**: https://pangrampangram.com
- **Tags**: specimen / warm / moderate

### Broadsheet discipline: hierarchy built from size ratios, decks, and kickers — not color. Hairline rules separate; small caps label; the reader always knows what matters most. Steal the ratio system (roughly 6:3:1 between hed, deck, body), not the look.
- **Source**: https://www.nytimes.com
- **Tags**: broadsheet / serious / dense

### Gallery restraint: images breathe inside generous whitespace, captions in one strict small-caps system, no decorative moves at all. Whitespace reads as luxury when the few elements present are impeccably aligned.
- **Source**: https://ok-rm.co.uk
- **Tags**: gallery / calm / sparse

### Scroll as essay: one reading column, type at genuine reading sizes with generous leading, hierarchy from spacing rather than scale jumps. Restraint as confidence — nothing shouts, everything is considered.
- **Source**: https://frankchimero.com
- **Tags**: scroll / calm / moderate

### Stack of self-contained color fields: each section is its own poster with its own background commitment, so scrolling reads like flipping a deck. Works when each panel makes ONE move; fails when panels hedge.
- **Source**: https://cargo.site
- **Tags**: stack / playful / moderate

### Index as interface: the entire archive is a typographic list — one row per project, no thumbnails, typography and numbering do all the work. Dense, fast, and confident; the anti-gallery.
- **Source**: https://www.experimentaljetset.nl
- **Tags**: index / minimal / dense
