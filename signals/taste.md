# Owner Taste Memory

Permanent, hand-curated. Unlike the rolling ratings/lessons windows, nothing
here expires — these are all-time truths, not recent trends. Edit by hand;
the pipeline never writes to this file.

## Gold standards — the execution bar

- **2026-04-28, drenched terracotta Specimen (risk 8).** A single hue
  committed across ~70% of the viewport, type waterfall reversed out of the
  field, labels and size markers treated as design material, not
  afterthoughts. Rated the benchmark: a committed gesture, not a hedge. This
  is the bar every build is measured against.
- **2026-06-13, fairway Split.** Left panel is the thesis (one enormous
  word, drenched fairway green), right panel is the evidence (clean
  cataloged rows). The split works because the two halves need each other —
  productive irony, the word for smallness rendered as the biggest object on
  the page.

## Standing complaints — do not repeat

- **Header keeps breaking.** Called out three ratings running (2026-07-20,
  -22, -23): "header is messed up," rounded corners read wrong, top
  navigation disliked outright. Header is not a solved problem — treat it
  as first-class design surface, not a template default.
- **Reads as templated, not designed.** 2026-07-22: "still feels like it is
  cycling through 4 or 5 different templates." Variance between builds must
  come from a genuine compositional decision, never from swapping a layout
  off a shortlist.
- **Brand lockup must be the real circular mark, never a placeholder.**
  2026-07-10: a shipped build kept the wordmark text but dropped the mark —
  graded down. 2026-07-22: "missing my personal brand, it is a gray box."
  The circular mark is the fixed element of the brand contract; wherever
  the mockup shows it (nav, header, footer), the render must too.
